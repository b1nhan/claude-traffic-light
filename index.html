GIỚI THIỆU
Vì sao cần đèn giao thông cho Claude Code?
Claude Code có thể chạy hàng chục phút mà không cần bạn động tay — cho đến khi nó cần xác nhận một thao tác. Nếu bạn đang làm việc khác, rất dễ bỏ lỡ. Claude Traffic Light biến trạng thái của Claude Code thành một tín hiệu bạn không thể bỏ qua, dù đang ở cửa sổ nào.
CHỜ XÁC NHẬN
Claude cần bạn duyệt một thao tác, hỏi thông tin, xác nhận yêu cầu,... trước khi tiếp tục.
ĐANG CHẠY
Claude Code đang xử lý — nhận prompt, chạy tool, suy nghĩ bước tiếp theo.
XONG VIỆC
Task đã xong, sẵn sàng nhận việc mới — quay lại tiếp tục ngay.
CÁCH SỬ DỤNG
Chỉ 3 bước để bắt đầu
1
Chạy app
Mở app desktop (hoặc file .exe portable) — cửa sổ nổi, tray icon và server nhúng cùng khởi động.
2
Nối Claude Code
Chọn 1 trong 3 cách ngay trong app: bấm "Connect to Claude" để tự động, chạy sẵn 1 script PowerShell, hoặc nhờ Claude Code tự cấu hình giúp bạn.
3
Theo dõi trạng thái
Vậy là xong! Từ giờ, mỗi khi Claude chạy tool, cần xác nhận hoặc xong việc — app đều đổi màu real-time.
