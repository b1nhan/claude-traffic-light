Claude Traffic Light

Đèn giao thông ảo cho Claude Code — chạy ngay trên máy bạn, không cần cài server rời.
🔴 đỏ = Claude đang chờ xác nhận  ·  🟡 vàng = đang chạy  ·  🟢 xanh = xong việc.

Cách 1 — Kết nối tự động (khuyên dùng)

Bấm nút bên dưới để tự động thêm cấu hình vào Claude Code. Chỉ cần làm 1 lần duy nhất.

Cách 2 — Chạy script (nếu Cách 1 không được)

Mở thư mục chứa connect-claude.ps1, chuột phải file đó → Run with PowerShell. Hoặc copy lệnh rồi dán vào cửa sổ PowerShell.

Cách 3 — Nhờ Claude tự setup

Copy đoạn dưới, dán vào cửa sổ Claude Code của bạn — Claude sẽ tự đọc và cấu hình giúp.

Sau khi làm xong 1 trong 3 cách, hãy khởi động lại Claude Code để áp dụng.
