Widget Opacity Preview

Mở file này bằng Live Server để chỉnh trực tiếp, không cần build lại app Electron. Sửa widget.css / widget-render.js ở đây sẽ áp dụng luôn cho widget thật (index.html dùng chung 2 file này).
Bấm vào tên mức để xem trước. Sửa số "Đèn"/"Nền" của mức đang chọn để widget cập nhật ngay. Lưu tự động vào trình duyệt (localStorage), không mất khi tải lại trang.
